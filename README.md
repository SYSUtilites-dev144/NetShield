Лёгкий монитор сетевых TCP-соединений для Windows в реальном времени. Написан на чистом C++ и WinAPI, без внешних зависимостей. Показывает, какие процессы выходят в интернет, куда именно они подключаются, и оценивает уровень угрозы каждого соединения. Аналог `netstat` и TCPView, но с цветовой индикацией, живым поиском и дашбордом.

## Быстрый старт

Готовый исполняемый файл уже находится в репозитории. Компилировать ничего не нужно.

1. Скачайте `netshield.exe` из этого репозитория.
2. Запустите его. Для отображения имён всех процессов используйте запуск от имени администратора (правый клик → Запуск от имени администратора).
3. Готово. Без установки, без компиляции, без зависимостей.

## Возможности

- Мониторинг TCP-соединений в реальном времени (обновление каждые 3 секунды).
- Цветовая индикация угроз: зелёный (безопасно), жёлтый (низкий), оранжевый (средний), красный (высокий).
- Живой поиск по процессу, IP-адресу, стране или состоянию.
- Пауза и возобновление обновления.
- Копирование удалённого IP в буфер обмена (двойной клик по строке).
- Определение страны по IP через GeoIP (ipapi.co).
- График активности по выбранному процессу (правый клик).
- Дашборд: топ стран и топ процессов по количеству соединений.
- Белый список доверенных процессов (NVIDIA, Steam, Chrome, системные службы) для снижения ложных срабатываний.
- Умная прокрутка — список не сбрасывается при обновлении.

## Уровни угроз

| Цвет | Уровень | Пример |
|------|---------|--------|
| Зелёный | SAFE | Известный процесс, стандартный порт |
| Жёлтый | LOW | Локальная сеть, прослушивание порта |
| Оранжевый | MEDIUM | Неизвестный процесс, нестандартный порт |
| Красный | HIGH | Неизвестный процесс + подозрительный порт или SYN_SENT |

## Использование

1. Наблюдайте за таблицей соединений. Цвет строки соответствует уровню угрозы.
2. Используйте поле поиска для фильтрации по процессу, IP, стране или состоянию.
3. Нажмите `Pause`, чтобы остановить обновление и изучить конкретную строку.
4. Двойной клик по строке копирует удалённый IP в буфер обмена.
5. Правый клик по строке открывает график активности процесса.
6. Дашборд справа показывает топ стран и топ процессов-источников соединений.

## Сборка из исходников (для разработчиков)

Если хотите собрать программу самостоятельно, потребуется MinGW-w64 (g++):

```bash
g++ -std=c++17 -mwindows -o netshield.exe netshield.cpp -lgdi32 -lcomctl32 -liphlpapi -lws2_32 -lpsapi -lwinhttp -lshell32
```

## Технологии
